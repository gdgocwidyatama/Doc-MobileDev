## Pilar Praktikum: Make Apps From Scratch

<CardGrid>
  <Card title="True Blank Canvas" icon="pencil">
    Mulai dari Scaffold kosong memplong bersama instruktur. Kamu merakit sendiri antarmuka baris demi baris tanpa magic code yang bikin bingung.
  </Card>
  <Card title="Incremental Dependencies" icon="seti:gradle">
    Dependensi dipasang bertahap tepat saat sesi membutuhkannya: Splash API di Sesi 1, DataStore Preferences di Sesi 3, OkHttp & Coil di Sesi 5.
  </Card>
  <Card title="Physical Device First" icon="laptop">
    Deploy langsung ke HP fisik via kabel data USB atau Wireless Debugging sejak sesi pertama dengan dukungan `enableEdgeToEdge()`.
  </Card>
  <Card title="Material 3 & Monet" icon="sun">
    Memahami sistem semantic token Material 3, dynamic color sistem Android, dan cara memecah komponen reusable yang rapi.
  </Card>
  <Card title="Modern Architecture" icon="seti:kotlin">
    Membangun alur UI deklaratif berbasis state menggunakan `remember`, `mutableStateOf`, Coroutines, dan Repository Pattern.
  </Card>
  <Card title="Portfolio Capstone Project" icon="rocket">
    Aplikasi LuminaWalls dikompilasi ke APK rilis teroptimasi dengan R8/ProGuard dan dikumpulkan sebagai portofolio nyata hasil belajar.
  </Card>
</CardGrid>

## Ekosistem Modern & Integrasi AI

<CardGrid>
  <Card title="llms.txt Integrated" icon="open-book">
    Mendukung standar [`llms.txt`](/llms.txt) resmi untuk AI Agent & LLM (Cursor, Claude Code, Copilot). Agent coding kamu otomatis paham arsitektur Compose murni dan Version Catalog proyek.
  </Card>
  <Card title="Code-First & Copy-Ready" icon="laptop">
    Disusun khusus untuk kecepatan praktik peserta di kelas. Potongan kode bersih, penunjuk path file presisi, dan pemecahan TODO bertahap tanpa teori berbelit-belit.
  </Card>
  <Card title="Cloudflare Pages Edge" icon="rocket">
    Dihosting di atas jaringan global Cloudflare Pages dengan arsitektur statis Astro 7.x yang super ringan, bebas lag, dan selalu siap diakses di mana saja.
  </Card>
</CardGrid>

## Roadmap 5 Pertemuan Study Jam

<div class="roadmap-table">

| Sesi | Topik Materi | Target Hands-on & Checkpoint |
|---|---|---|
| [**Sesi&nbsp;1**](/sesi-1/) | Environment Setup, First App Launch & Git on GitHub | Colok HP fisik, run app Compose perdana (`enableEdgeToEdge`), pasang Splash API (`core-splashscreen`), dan push ke repo fork masing-masing. |
| [**Sesi&nbsp;2**](/sesi-2/) | App Gateway & Setup Wizard - Thinking in Compose Basics | Kanvas kosong (*true blank canvas*), Setup Wizard 3 langkah, gerbang state `isSetupCompleted`, dan Stacking Card perdana (`Box` + Scrim Gradient). |
| [**Sesi&nbsp;3**](/sesi-3/) | Stacking Cards, Settings Theme Switcher & Floating Nav Bar | Katalog galeri 2 kolom `LazyVerticalGrid`, simpan preferensi ke DataStore, Theme Switcher 3 mode (Dark/Light/System), dan `FloatingNavBar`. |
| [**Sesi&nbsp;4**](/sesi-4/) | Material 3 Design - Tokens, Component Reuse & Contributors Screen | M3 semantic color tokens, badge label reusable `WallpaperTag`, tombol Back adaptif, dan halaman `ContributorsScreen` via GitHub API. |
| [**Sesi&nbsp;5**](/sesi-5/) | Capstone Showcase - Remote API, Coil, Native WallpaperManager, R8 & Submission | LuminaWalls Full App: integrasi remote API Cloudflare Worker, asinkron image loading Coil, pasang wallpaper native ke HP fisik, build APK R8, dan pengumpulan Capstone. |

</div>
