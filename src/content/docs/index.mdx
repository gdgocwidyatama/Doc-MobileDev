<CardGrid>
  <Card title="True Blank Canvas" icon="pencil">

  </Card>
  <Card title="Incremental Dependencies" icon="seti:gradle">

  </Card>
  <Card title="Physical Device First" icon="laptop">

  </Card>

  </Card>
  <Card title="Modern Architecture" icon="seti:kotlin">

  </Card>

    Aplikasi LuminaWalls dikompilasi ke APK rilis teroptimasi dengan R8/ProGuard dan dikumpulkan sebagai portofolio nyata hasil belajar.

## Roadmap 5 Pertemuan Study Jam

| Sesi | Topik Materi | Target Hands-on & Checkpoint |
|---|---|---|
| [**Sesi 1**](/sesi-1/) | Environment Setup, First App Launch & Git on GitHub | Colok HP fisik, run app Compose perdana (`enableEdgeToEdge`), pasang Splash API (`core-splashscreen`), dan push ke repo fork masing-masing. |
| [**Sesi 2**](/sesi-2/) | App Gateway & Setup Wizard - Thinking in Compose Basics | Kanvas kosong (*true blank canvas*), Setup Wizard 3 langkah, gerbang state `isSetupCompleted`, dan Stacking Card perdana (`Box` + Scrim Gradient). |
| [**Sesi 3**](/sesi-3/) | Stacking Cards, Settings Theme Switcher & Floating Nav Bar | Katalog galeri 2 kolom `LazyVerticalGrid`, simpan preferensi ke DataStore, Theme Switcher 3 mode (Dark/Light/System), dan `FloatingNavBar`. |
| [**Sesi 4**](/sesi-4/) | Material 3 Design - Tokens, Component Reuse & Contributors Screen | M3 semantic color tokens, badge label reusable `WallpaperTag`, tombol Back adaptif, dan halaman `ContributorsScreen` via GitHub API. |
| [**Sesi 5**](/sesi-5/) | Capstone Showcase - Remote API, Coil, Native WallpaperManager, R8 & Submission | LuminaWalls Full App: integrasi remote API Cloudflare Worker, asinkron image loading Coil, pasang wallpaper native ke HP fisik, build APK R8, dan pengumpulan Capstone. |
